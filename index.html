C++.
Un’istruzione alla volta.

Una guida per capire il codice, dai primi programmi alle strutture. Spiegazioni chiare, esempi commentati e risultati da leggere insieme.

Tutto parte da poche righe

Un programma può iniziare con un messaggio. Questo esempio è completo: le istruzioni tra le graffe vengono eseguite quando il programma parte.

C++
#include <iostream>
using namespace std;

int main() {
    cout << "Ciao, C++!" << endl;
    return 0;
}
Risultato dell’esempio
Ciao, C++!

Come leggere gli esempi

Leggi prima la spiegazione, poi segui le istruzioni nell’ordine in cui sono scritte. Il risultato mostrato sotto il codice ti permette di collegare ogni operazione al suo effetto.

I blocchi con #include e main sono programmi completi. Gli altri sono frammenti da inserire nel corpo di main, aggiungendo gli header indicati: <string> per il testo, <cmath> per la matematica e <algorithm> per min e max. Le definizioni di strutture possono stare prima di main. Gli esempi sono adatti a C++17 o successivo.

Introduzione

Programmare significa trasformare un ragionamento in istruzioni precise. In questa guida il punto di partenza è semplice: scrivere piccoli programmi C++ e capire che cosa fa ogni riga.

Che cos’è C++

C++ è un linguaggio di programmazione compilato: il codice sorgente viene tradotto prima di essere eseguito. Si usa per software di sistema, applicazioni e videogiochi, tra molti altri ambiti. Qui lavoreremo con programmi da console, che comunicano attraverso testi e numeri.

Un algoritmo è un procedimento per risolvere un problema. Per dividere una spesa tra amici, per esempio, consideri il totale e il numero di persone, dividi i due valori e comunichi la quota. Il codice rende espliciti questi passaggi.

Perché usare C++

C++ ti permette di esprimere calcoli, decisioni e ripetizioni e di scegliere come organizzare i dati. Scrivendo esempi piccoli impari anche a distinguere il risultato che desideri dalle istruzioni necessarie per ottenerlo.

All’inizio conta soprattutto saper seguire il flusso di un programma: quali dati entrano, come vengono elaborati e quale risultato esce.

C e C++

C++ è nato a partire dal linguaggio C e conserva molte forme della sua sintassi, ma i due linguaggi sono distinti. C++ offre strumenti aggiuntivi: in questa guida incontrerai, per esempio, string per il testo.

Non occorre conoscere C per iniziare questo percorso. È sufficiente procedere dai programmi più semplici verso quelli che gestiscono più dati.

Il primo risultato

Una prima istruzione può mostrare il risultato di un calcolo. In seguito sostituiremo i numeri fissi con dati memorizzati e valori letti dalla tastiera.

C++
cout << "Quota per persona: " << 36 / 4 << " euro" << endl;
Risultato dell’esempio
Quota per persona: 9 euro

Primi passi

Un programma nasce come testo in un file sorgente. Per farlo funzionare devi scriverlo, compilarlo e avviarlo.

Gli strumenti necessari

Un editor ti permette di scrivere il codice. Un compilatore controlla e traduce il sorgente. Un ambiente di sviluppo integrato, o IDE, riunisce editor e strumenti per costruire e avviare i programmi.

Per iniziare con questa guida consigliamo OnlineGDB: puoi scrivere, compilare ed eseguire gli esempi direttamente nel browser, senza installare programmi. Servono un browser e una connessione a Internet.

C++

Sintassi

La sintassi stabilisce come scrivere le istruzioni. Parentesi, virgolette, nomi e punti e virgola hanno un ruolo preciso.

La struttura di un programma

#include <iostream> rende disponibili gli strumenti di input e output. int main() identifica il punto di ingresso del programma. Le graffe delimitano il suo corpo; return 0; indica una conclusione regolare.

Le istruzioni nel corpo di main vengono eseguite dall’alto verso il basso, a meno che una scelta o un ciclo modifichino il percorso.

C++
#include <iostream>
using namespace std;

int main() {
    cout << "Inizio" << endl;
    cout << "Fine" << endl;
    return 0;
}
Risultato dell’esempio
Inizio
Fine

Con o senza namespace

La libreria standard usa il namespace std. Con using namespace std; puoi scrivere cout e cin direttamente. Senza questa dichiarazione scrivi std::cout e std::cin.

Sono due modi per riferirti agli stessi strumenti. Negli esempi più brevi useremo la prima forma; incontrerai anche la seconda, specialmente nei programmi più estesi.

C++
#include <iostream>

int main() {
    std::cout << "Ciao!" << std::endl;
    return 0;
}
Risultato dell’esempio
Ciao!

Istruzioni e punto e virgola

Molte istruzioni terminano con ;: per esempio una stampa, una dichiarazione o un’assegnazione. La direttiva #include non richiede questo simbolo. Un blocco tra graffe non è semplicemente una lunga istruzione da chiudere sempre con ;.

C++ distingue maiuscole e minuscole: cout è diverso da Cout. I rientri rendono leggibile il codice, ma sono le graffe a stabilire dove inizia e finisce un blocco.

Più istruzioni, un ordine

Due stampe consecutive comunicano i dati nello stesso ordine in cui sono scritte. Una riga di codice non crea da sola una nuova riga nell’output: devi richiederla con endl.

C++
cout << "Prima parte. ";
cout << "Seconda parte." << endl;
Risultato dell’esempio
Prima parte. Seconda parte.

Output

L’output è ciò che il programma comunica. Con cout puoi mostrare testi, numeri e risultati di calcoli.

Stampare testo

Dopo cout usa << e scrivi il testo tra virgolette doppie. Puoi unire più elementi nella stessa istruzione ripetendo <<. Gli spazi da visualizzare vanno inseriti esplicitamente.

C++
cout << "Benvenuto! ";
cout << "Il programma è pronto." << endl;
Risultato dell’esempio
Benvenuto! Il programma è pronto.

Stampare numeri e calcoli

Un numero senza virgolette è un valore. Un’espressione numerica viene calcolata; una scritta tra virgolette viene visualizzata così com’è.

C++
cout << "Calcolo: " << 3 * 8 << endl;
cout << "Testo: " << "3 * 8" << endl;
Risultato dell’esempio
Calcolo: 24
Testo: 3 * 8

Andare a capo

endl manda a capo e forza anche l’invio dell’output ancora in attesa. Si scrive fuori dalle virgolette, collegato a cout con <<. Due endl consecutivi lasciano una riga vuota.

C++
cout << "Prima riga" << endl << "Seconda riga" << endl << endl;
cout << "Dopo la riga vuota" << endl;
Risultato dell’esempio
Prima riga
Seconda riga

Dopo la riga vuota
Da ricordare. L’istruzione cout non aggiunge automaticamente spazi o ritorni a capo.

Commenti

I commenti sono note per chi legge il codice. Non vengono eseguiti e non compaiono nell’output.

Commenti su una riga

// apre un commento che termina alla fine della riga. Puoi scriverlo prima di un’istruzione oppure dopo. Un commento utile chiarisce il significato di un dato o il motivo di una scelta.

C++
// Ogni ingresso costa 6 euro.
cout << 3 * 6 << " euro" << endl; // Costo per tre persone.
Risultato dell’esempio
18 euro

Commenti su più righe

/* apre un commento e */ lo chiude. Il testo compreso tra i due simboli può occupare più righe. Questi commenti non vanno annidati uno dentro l’altro.

C++
/* Questo programma calcola il costo degli ingressi.
   Il trasporto viene pagato separatamente. */
cout << "Trasporto escluso" << endl;
Risultato dell’esempio
Trasporto escluso

Commento oppure testo?

All’interno delle virgolette, // è soltanto una parte della scritta. Il suo significato di commento vale quando compare nel codice al di fuori di un testo.

C++
cout << "// Questa scritta viene mostrata" << endl;
// Questa nota non viene mostrata.
Risultato dell’esempio
// Questa scritta viene mostrata

Variabili

Una variabile associa un nome a un valore di un certo tipo. Ti permette di memorizzare dati e riutilizzarli.

Dichiarare e inizializzare

Nella dichiarazione scrivi tipo e nome. L’inizializzazione assegna il primo valore. int è adatto a un conteggio intero; double a un numero che può avere decimali.

C++
int biglietti = 3;
double prezzo = 8.50;
double totale = biglietti * prezzo;
cout << totale << " euro" << endl;
Risultato dell’esempio
25.5 euro
Da ricordare. Inizializza una variabile prima di leggerla. La sola dichiarazione int punti; non assegna un punteggio iniziale valido.

Cambiare un valore

L’assegnazione = sostituisce il valore conservato nella variabile. Un risultato calcolato in precedenza non si aggiorna automaticamente quando cambia uno dei dati.

C++
int persone = 3;
int costo = persone * 5;
persone = 4;
cout << costo << endl; // È ancora il risultato precedente.
costo = persone * 5;
cout << costo << endl;
Risultato dell’esempio
15
20

Mostrare e sommare variabili

Per mostrare il valore usa il nome senza virgolette. Puoi combinarlo con un’etichetta e puoi usare più variabili in un calcolo.

C++
int mattina = 12;
int pomeriggio = 9;
cout << "Visitatori: " << mattina + pomeriggio << endl;
Risultato dell’esempio
Visitatori: 21

Dichiarazioni multiple

Variabili dello stesso tipo possono essere dichiarate sulla stessa riga, separate da virgole. Puoi anche assegnare lo stesso valore a più variabili, ma nomi e dichiarazioni separate spesso rendono più chiaro il ragionamento.

C++
int primo = 4, secondo = 7, terzo = 9;
cout << primo + secondo + terzo << endl;
int a = 0, b = 0, c = 0;
a = b = c = 5;
cout << a + b + c << endl;
Risultato dell’esempio
20
15

Identificatori: scegliere i nomi

Un identificatore è il nome con cui riconosci una variabile. Usa nomi come numeroStudenti o prezzoBiglietto, che descrivano il contenuto. Un nome non può iniziare con una cifra, contenere spazi o essere una parola riservata come int.

Per i primi programmi usa lettere senza accenti, cifre e, se serve, _. voto e Voto sono nomi diversi. Un nome significativo è più utile di un commento che deve spiegare continuamente una lettera generica.

Costanti

const impedisce di riassegnare il valore. Una costante di tipo semplice deve essere inizializzata alla dichiarazione. Scriverne il nome in maiuscolo è una convenzione, non ciò che la rende immutabile.

C++
const int POSTI = 25;
int occupati = 18;
cout << "Posti liberi: " << POSTI - occupati << endl;
Risultato dell’esempio
Posti liberi: 7

Un esempio concreto

Un totale può dipendere da quantità e prezzo unitario. Dare un nome ai dati permette di cambiare i valori senza riscrivere il calcolo.

C++
int quaderni = 4;
double prezzoUnitario = 2.50;
double spesa = quaderni * prezzoUnitario;
cout << "Spesa: " << spesa << " euro" << endl;
Risultato dell’esempio
Spesa: 10 euro

Input

L’input è ciò che il programma riceve. Con cin puoi leggere valori inseriti dalla tastiera e conservarli nelle variabili.

Leggere un valore

Dichiara la variabile, mostra una richiesta e leggi con cin >> variabile. L’operatore è >> per l’input e << per l’output.

C++
int quantita = 0;
cout << "Quanti quaderni? ";
cin >> quantita;
cout << "Hai scelto " << quantita << " quaderni." << endl;
Risultato dell’esempio
Quanti quaderni? 4
Hai scelto 4 quaderni.
Da ricordare. Negli esempi interattivi, il dato dopo la domanda è un possibile input dell’utente. Si presume che i dati inseriti siano del tipo richiesto.

Una semplice calcolatrice

Più letture possono fornire i dati di un calcolo. Usa double se vuoi ammettere valori decimali. Puoi leggere due variabili anche con cin >> primo >> secondo;.

C++
double primo = 0.0;
double secondo = 0.0;
cout << "Primo numero: ";
cin >> primo;
cout << "Secondo numero: ";
cin >> secondo;
cout << "Somma: " << primo + secondo << endl;
Risultato dell’esempio
Primo numero: 2.5
Secondo numero: 4
Somma: 6.5

Il dato deve corrispondere al tipo

Scrivi i decimali con il punto, per esempio 7.5. Una parola come sette non è un input numerico valido. Se una lettura fallisce, non puoi trattare i dati successivi come se tutto fosse riuscito.

Con una stringa, cin >> nome legge una parola alla volta. Per un’intera riga con spazi userai getline, illustrato nel capitolo sulle stringhe.

Tipi di dati

Il tipo descrive quali valori una variabile può conservare. Sceglilo in base al significato del dato, non solo alla sua forma.

I tipi di base

Un conteggio richiede un intero, una temperatura può avere decimali e una risposta sì/no richiede un booleano. Per il testo usa string, includendo <string>.

TipoChe cosa rappresentaEsempio
intNumero interoint assenti = 2;
floatNumero con decimalifloat tempo = 9.5f;
doubleNumero con decimali, normalmente più preciso di floatdouble distanza = 1.75;
boolVero o falsobool presente = true;
charSingolo caratterechar sezione = 'B';
stringTestostring nome = "Alex";
Da ricordare. Dimensioni e intervalli dei tipi dipendono dall’implementazione. Non assumere che un int abbia sempre lo stesso numero di byte su ogni sistema.

Numeri interi e decimali

int non conserva una parte frazionaria. float e double rappresentano valori con decimali ma hanno precisione finita: molti numeri vengono memorizzati come approssimazioni. Nei calcoli introduttivi useremo di solito double.

La notazione scientifica usa e: 1.5e3 significa 1.5 × 1000, cioè 1500. Il suffisso f, come in 9.5f, indica un valore letterale di tipo float.

Conversioni e divisione intera

Assegnando un valore decimale a int, la parte frazionaria viene scartata, non arrotondata. In una divisione tra due interi, il risultato è intero. Assegnarlo dopo a double non recupera la parte già persa.

C++
int intero = 7.9;         // Diventa 7.
double a = 7 / 2;         // Prima 7 / 2 dà 3.
double b = 7 / 2.0;       // Almeno un operando è decimale.
cout << intero << endl;
cout << a << endl;
cout << b << endl;
Risultato dell’esempio
7
3
3.5
Da ricordare. Per la media di 7 e 8 usa (7 + 8) / 2.0. La variabile risultato può essere double, ma conta anche il tipo degli operandi del calcolo.

Valori booleani

bool può assumere true o false. È adatto a informazioni come “presente” o “disponibile”. In una normale stampa i due valori compaiono come 1 e 0.

C++
bool presente = true;
bool disponibile = false;
cout << presente << " " << disponibile << endl;
Risultato dell’esempio
1 0

Caratteri

char conserva un singolo carattere. Usa apici singoli: 'A', non "A", che è un testo. Puoi usarlo per una sezione o una scelta rappresentata da una lettera.

Un carattere è memorizzato attraverso un codice numerico. Su sistemi con codifica compatibile con ASCII, per esempio, il codice 65 corrisponde ad A. Scrivere direttamente 'A' rende chiaro il significato.

Testo con string

Una variabile string conserva una sequenza di caratteri e usa virgolette doppie. Può contenere più parole e spazi. È distinta da char, che rappresenta un solo carattere.

C++
string nome = "Alex Rossi";
char iniziale = 'A';
cout << nome << " - " << iniziale << endl;
Risultato dell’esempio
Alex Rossi - A

Dedurre il tipo con auto

auto lascia al compilatore la deduzione del tipo a partire dall’inizializzazione. Il tipo dedotto resta lo stesso per tutta la vita della variabile: auto non significa “tipo che cambia”.

C++
auto quantita = 4;       // int
auto prezzo = 2.50;      // double
auto lettera = 'B';      // char
auto pronto = true;      // bool
auto nome = string("Alex"); // string
quantita = 9.9;          // Conversione a int: il valore diventa 9.
cout << quantita << endl;
Risultato dell’esempio
9
Da ricordare. auto testo = "Alex"; non deduce string. Quando vuoi una string con auto, scrivi auto testo = string("Alex"); e includi <string>.

Scegliere i tipi in un caso concreto

Per descrivere un acquisto puoi usare un intero per la quantità e un decimale per il prezzo. La scelta comunica che sono possibili prezzi con centesimi ma non, in questo esempio, mezzi quaderni.

C++
int quantita = 3;
double prezzo = 1.80;
bool consegnato = false;
cout << "Totale: " << quantita * prezzo << endl;
cout << "Consegnato: " << consegnato << endl;
Risultato dell’esempio
Totale: 5.4
Consegnato: 0

Operatori

Gli operatori indicano operazioni su valori e variabili: calcolare, assegnare, confrontare e combinare condizioni.

Operatori aritmetici

+, -, * e / rappresentano somma, sottrazione, prodotto e divisione. % calcola il resto di una divisione tra interi. La divisione intera scarta la parte frazionaria.

OperatoreOperazioneRisultato dell’esempio
+Somma8 + 3 → 11
-Sottrazione8 - 3 → 5
*Prodotto8 * 3 → 24
/Divisione8 / 3 → 2
%Resto tra interi8 % 3 → 2
Da ricordare. Non dividere per zero. Per un risultato decimale usa, per esempio, 8 / 3.0.

Incremento e decremento

++ aumenta una variabile di uno; -- la diminuisce di uno. Nell’esempio di questa sottosezione sono istruzioni autonome: punti++ e ++punti producono lo stesso aggiornamento. Negli altri esempi preferiamo le forme estese punti = punti + 1 e punti = punti - 1.

C++
int punti = 5;
punti++;
cout << punti << endl;
punti--;
cout << punti << endl;
Risultato dell’esempio
6
5

Assegnazione e forme abbreviate

= assegna il valore calcolato a destra alla variabile a sinistra. +=, -=, *=, /= e %= combinano un’operazione con un’assegnazione.

C++
int risparmio = 10;
risparmio += 5; // Come risparmio = risparmio + 5.
risparmio *= 2;
risparmio -= 3;
cout << risparmio << endl;
Risultato dell’esempio
27

Confronti

Un confronto produce un risultato booleano: vero oppure falso. == confronta l’uguaglianza; = assegna. Questa distinzione è fondamentale quando scriverai le condizioni.

OperatoreDomandaEsempio
==Sono uguali?voto == 6
!=Sono diversi?voto != 6
<Il primo è minore?voto < 6
<=È minore o uguale?voto <= 6
>È maggiore?voto > 6
>=È maggiore o uguale?voto >= 6

Operatori logici

&& richiede che entrambe le condizioni siano vere; || richiede che almeno una sia vera; ! inverte il valore booleano. Le due barre di || sono il carattere barra verticale.

C++
int voto = 7;
bool valido = voto >= 1 && voto <= 10;
bool fuoriIntervallo = voto < 1 || voto > 10;
cout << valido << " " << fuoriIntervallo << endl;
cout << !valido << endl;
Risultato dell’esempio
1 0
0
Da ricordare. Scrivi voto >= 1 && voto <= 10, non 1 <= voto <= 10. I confronti concatenati non hanno in C++ il significato della notazione matematica.

Precedenza degli operatori

In un’espressione, prodotti e divisioni precedono somme e sottrazioni. Tra operatori aritmetici dello stesso livello come + e -, il raggruppamento è da sinistra a destra. Le parentesi permettono di rendere esplicito il calcolo voluto.

Per le condizioni ricorda che i confronti precedono &&, e && precede ||. Anche quando non sono obbligatorie, le parentesi possono rendere più leggibile una combinazione.

C++
cout << 2 + 3 * 4 << endl;
cout << (2 + 3) * 4 << endl;
cout << 20 - 6 + 2 << endl;
cout << 20 - (6 + 2) << endl;
Risultato dell’esempio
14
20
16
12

Stringhe

Le stringhe rappresentano testo. Puoi unirle, leggerle, conoscere la loro lunghezza e lavorare con i singoli caratteri.

Dichiarare una stringa

Includi <string> e dichiara una variabile di tipo string. Una stringa può essere vuota oppure contenere parole, spazi e punteggiatura.

C++
#include <iostream>
#include <string>
using namespace std;

int main() {
    string messaggio = "Il programma è pronto.";
    cout << messaggio << endl;
    return 0;
}
Risultato dell’esempio
Il programma è pronto.

Concatenazione

Concatenare significa unire testi. Usa + tra stringhe e inserisci gli spazi che vuoi conservare nel risultato. La forma += aggiunge testo alla stringa esistente.

C++
string nome = "Alex";
string cognome = "Rossi";
string completo = nome + " " + cognome;
completo = completo + "!";
cout << completo << endl;
Risultato dell’esempio
Alex Rossi!

Aggiungere testo con append

Anche .append() aggiunge testo alla stringa su cui viene chiamato. Modifica quella stringa: non si limita a produrre una scritta per la stampa.

C++
string saluto = "Ciao, ";
saluto.append("Alex");
cout << saluto << endl;
Risultato dell’esempio
Ciao, Alex

Numeri e stringhe

La somma di numeri e l’unione di testi sono operazioni diverse. "12" è testo, anche se contiene cifre. Non puoi concatenare direttamente una string e un numero con +.

C++
int a = 12, b = 3;
string primo = "12", secondo = "3";
cout << a + b << endl;
cout << primo + secondo << endl;
cout << "Punteggio: " << a << endl;
Risultato dell’esempio
15
123
Punteggio: 12
Da ricordare. Per visualizzare testo e numeri insieme puoi usare più << con cout, senza trasformarli in una sola stringa.

Lunghezza: length e size

.length() e .size() forniscono la lunghezza della stringa e, per string, hanno lo stesso risultato. Gli spazi sono inclusi.

C++
string nome = "Alex Rossi";
cout << nome.length() << endl;
cout << nome.size() << endl;
Risultato dell’esempio

10
Da ricordare. Gli esempi sugli indici usano testo semplice. In UTF-8 una lettera accentata o un’emoji può occupare più byte: la lunghezza di string non conta necessariamente i simboli che vedi.

Accesso e modifica dei caratteri

Il primo carattere ha indice 0. Per una stringa di quattro elementi, gli indici dei caratteri sono 0, 1, 2 e 3. Il carattere da assegnare usa apici singoli.

C++
string parola = "casa";
cout << parola[0] << endl;
cout << parola[parola.length() - 1] << endl;
parola[0] = 'r';
cout << parola << endl;
Risultato dell’esempio
c
a
rasa
Da ricordare. L’ultimo indice è lunghezza - 1, non lunghezza. Non cercare il primo o l’ultimo carattere se la stringa è vuota.

Accesso controllato con at

.at(indice) permette di leggere o modificare un carattere come le parentesi quadre. La differenza è che controlla se l’indice identifica un carattere valido e segnala un errore se è fuori intervallo.

C++
string parola = "mare";
cout << parola.at(1) << endl;
parola.at(0) = 'f';
cout << parola << endl;
Risultato dell’esempio

fare

Caratteri speciali

Alcuni caratteri richiedono una sequenza di escape. " rappresenta una virgoletta doppia, \ una barra inversa e una tabulazione. Per andare a capo negli esempi usiamo endl, fuori dalla stringa.

C++
cout << "La parola \"ciao\" ha quattro lettere." << endl;
cout << "Cartella: C:\\documenti" << endl;
Risultato dell’esempio
La parola "ciao" ha quattro lettere.
Cartella: C:\documenti

Leggere una parola o una riga

cin >> testo legge fino a uno spazio; getline(cin, testo) legge la riga, inclusi gli spazi, fino al ritorno a capo. Per nomi completi e titoli la seconda forma è di solito quella adatta.

C++
string nome;
cout << "Nome e cognome: ";
getline(cin, nome);
cout << "Ciao, " << nome << "!" << endl;
Risultato dell’esempio
Nome e cognome: Alex Rossi
Ciao, Alex Rossi!

getline dopo un numero

Una lettura con cin >> numero può lasciare il ritorno a capo da consumare. Una successiva getline(cin, nome) lo leggerebbe subito come fine della riga. Per un nome usa getline(cin >> ws, nome);.

ws scarta gli spazi iniziali, compresi i ritorni a capo. È adatto a nomi e titoli, ma non quando devi conservare spazi iniziali o leggere una riga vuota.

C++
int eta = 0;
string nome;
cout << "Età: ";
cin >> eta;
cout << "Nome completo: ";
getline(cin >> ws, nome);
cout << nome << ", " << eta << " anni" << endl;
Risultato dell’esempio
Età: 16
Nome completo: Alex Rossi
Alex Rossi, 16 anni

Stringhe senza using namespace

Anche string appartiene a std. Se ometti using namespace std;, usa std::string, std::cout, std::cin e std::getline.

C++
std::string nome = "Alex";
std::cout << nome << std::endl;
Risultato dell’esempio
Alex

Stringhe in stile C

C++ supporta anche testi conservati in un array di char. Una stringa in stile C termina con il carattere nullo \0, che indica la fine del testo. Per i programmi di questa guida è più comodo lavorare con string.

L’esempio seguente usa due rappresentazioni diverse dello stesso testo. L’array di caratteri verrà ritrovato nel capitolo sugli array; non possiede i metodi .length() e .append() di string.

C++
string testo = "Ciao";

Matematica

Oltre agli operatori, la libreria standard mette a disposizione strumenti per radici, arrotondamenti e altri calcoli.

Minimo e massimo

min(a, b) restituisce il minore dei due valori e max(a, b) il maggiore. Includi <algorithm> e usa due argomenti dello stesso tipo.

C++
cout << min(14, 19) << endl;
cout << max(14, 19) << endl;

19

L’ipotenusa di un triangolo rettangolo si ottiene dalla radice della somma dei quadrati dei cateti. Per un quadrato basta moltiplicare un valore per se stesso.

Booleani

Un booleano rappresenta una condizione: vera oppure falsa. È il punto di collegamento tra dati e decisioni.

Vero e falso

Le costanti true e false sono i valori del tipo bool. Con la formattazione normale, cout li mostra come 1 e 0.

C++
bool aperto = true;
bool esaurito = false;
cout << aperto << " " << esaurito << endl;
Risultato dell’esempio
1 0

Mostrare true e false con boolalpha

boolalpha modifica la formattazione dell’output booleano. Dopo averlo inserito in cout, i booleani vengono mostrati come parole. noboolalpha ripristina 1 e 0.

C++
bool disponibile = true;
cout << boolalpha << disponibile << endl;
cout << noboolalpha << disponibile << endl;
Risultato dell’esempio
true
1
Da ricordare. boolalpha è una impostazione dell’output, non un nuovo tipo di dato. Rimane attiva finché non la cambi.

Espressioni booleane

Un confronto produce un valore booleano. Puoi stamparlo direttamente oppure conservarlo in una variabile con un nome significativo. Il valore conservato non si ricalcola da solo se cambiano i dati.

C++
int voto = 7;
bool sufficiente = voto >= 6;
cout << boolalpha << sufficiente << endl;
voto = 4;
sufficiente = voto >= 6;
cout << sufficiente << endl;
Risultato dell’esempio
true
false

Un esempio concreto

Un prestito è possibile solo se la tessera è valida e il libro è disponibile. L’operatore && esprime questa necessità di due condizioni vere.

C++
bool tesseraValida = true;
bool libroDisponibile = false;
bool prestitoPossibile = tesseraValida && libroDisponibile;
cout << boolalpha << prestitoPossibile << endl;
Risultato dell’esempio
false

If…Else

Una condizione permette al programma di scegliere quali istruzioni eseguire. Non tutti i programmi seguono sempre lo stesso percorso.

La scelta con if

if esegue il blocco quando la condizione tra parentesi è vera. Puoi scrivere direttamente un confronto oppure usare una variabile booleana.

C++
int voto = 7;
if (voto >= 6) {
    cout << "Risultato sufficiente" << endl;
}
Risultato dell’esempio
Risultato sufficiente
Da ricordare. Non inserire ; subito dopo if (condizione): creerebbe un’istruzione vuota separata dal blocco che volevi controllare.

L’alternativa con else

else esegue il ramo alternativo se la condizione dell’if è falsa. I due rami sono alternativi: per quella scelta ne viene eseguito uno solo.

C++
int voto = 4;
if (voto >= 6) {
    cout << "Sufficiente" << endl;
} else {
    cout << "Da recuperare" << endl;
}
Risultato dell’esempio
Da recuperare

Più alternative con else if

Una catena di condizioni procede dall’alto e si ferma al primo ramo vero. L’ordine dei controlli conta: controllando prima voto >= 6, un 9 verrebbe già classificato come sufficiente.

C++
int voto = 9;
if (voto < 1 || voto > 10) {
    cout << "Voto fuori intervallo" << endl;
} else if (voto >= 8) {
    cout << "Ottimo risultato" << endl;
} else if (voto >= 6) {
    cout << "Sufficiente" << endl;
} else {
    cout << "Da recuperare" << endl;
}
Risultato dell’esempio
Ottimo risultato

La forma breve: operatore ternario

condizione ? valoreSeVero : valoreSeFalso sceglie tra due valori. È utile per assegnazioni brevi; per più istruzioni mantieni un normale if…else.

C++
int voto = 7;
string esito = voto >= 6 ? "sufficiente" : "da recuperare";
cout << esito << endl;
Risultato dell’esempio
sufficiente

Ternari annidati

Un ternario può contenere un altro ternario. La forma permette tre alternative, ma richiede più attenzione alla lettura. Le parentesi rendono evidente quale parte costituisce la seconda scelta.

C++
int numero = 0;
string segno = numero > 0 ? "positivo"
             : (numero < 0 ? "negativo" : "zero");
cout << segno << endl;
Risultato dell’esempio
zero

If annidati

Puoi mettere un if dentro un altro quando una scelta dipende da una precedente. Il controllo interno viene raggiunto soltanto entrando nel ramo esterno.

C++
bool tesseraValida = true;
bool libroDisponibile = false;
if (tesseraValida) {
    if (libroDisponibile) {
        cout << "Prestito possibile" << endl;
    } else {
        cout << "Libro non disponibile" << endl;
    }
} else {
    cout << "Serve una tessera valida" << endl;
}
Risultato dell’esempio
Libro non disponibile

Condizioni con AND, OR e NOT

&& combina requisiti che devono valere insieme; || alternative di cui almeno una deve valere; ! nega una condizione. Aggiungi parentesi quando vuoi rendere immediata la lettura.

C++
int voto = 7;
bool assente = false;
if ((voto >= 6 && voto <= 10) && !assente) {
    cout << "Risultato registrato" << endl;
}
Risultato dell’esempio
Risultato registrato

Un esempio con valori di confine

Se un controllo usa >= 6, il valore 6 è compreso e 5 è escluso. Per classificare un intero come positivo, negativo o nullo, controlla prima i casi non nulli e lascia lo zero all’ultimo ramo.

C++
int numero = -3;
if (numero > 0) {
    cout << "Positivo" << endl;
} else if (numero < 0) {
    cout << "Negativo" << endl;
} else {
    cout << "Zero" << endl;
}
Risultato dell’esempio
Negativo

Switch

Quando una scelta corrisponde a valori precisi, switch rende visibili i diversi casi in un unico blocco.

Scegliere un caso

switch valuta il valore e cerca il case corrispondente. Negli esempi useremo un intero o un carattere. Per intervalli come “almeno 6” usa invece if.

C++
int scelta = 2;
switch (scelta) {
    case 1:
        cout << "Acqua" << endl;
        break;
    case 2:
        cout << "Succo" << endl;
        break;
    case 3:
        cout << "Tè" << endl;
        break;
    default:
        cout << "Scelta non prevista" << endl;
}
Risultato dell’esempio
Succo
Da ricordare. I case contengono valori costanti, non condizioni come scelta > 2. In questo percorso non usare switch con string o double.

Il ruolo di break

break termina lo switch. Senza di esso, dopo un caso corrispondente l’esecuzione continua anche nelle istruzioni dei casi successivi. Puoi sfruttarlo intenzionalmente per più casi con lo stesso risultato.

C++
int giorno = 7;
switch (giorno) {
    case 6:
    case 7:
        cout << "Fine settimana" << endl;
        break;
    default:
        cout << "Altro giorno" << endl;
}
Risultato dell’esempio
Fine settimana

Il caso default

default gestisce il valore che non corrisponde ad alcun case. Non è obbligatorio, ma nei menu aiuta a comunicare una scelta non prevista. Se si trova alla fine, può terminare senza break perché il blocco finisce lì.

While

Un ciclo ripete un blocco di istruzioni. Con while la ripetizione continua finché una condizione resta vera.

La condizione viene controllata prima

while controlla la condizione prima di ogni giro. Se è falsa già all’inizio, il corpo non viene eseguito. Qualcosa deve permettere alla condizione di diventare falsa, oppure devi prevedere una uscita.

C++
int contatore = 3;
while (contatore > 0) {
    cout << contatore << endl;
    contatore = contatore - 1;
}
cout << "Via!" << endl;
Risultato dell’esempio
3
2
1
Via!
Da ricordare. Senza contatore = contatore - 1, il valore resterebbe 3 e il ciclo continuerebbe indefinitamente.

Seguire i valori durante il ciclo

Il controllo si ripete dopo l’aggiornamento. Quando il contatore arriva a 0, la condizione è falsa e il programma prosegue dopo il blocco.

Valore al controllocontatore > 0Che cosa succede
3trueStampa 3; diventa 2
2trueStampa 2; diventa 1
1trueStampa 1; diventa 0
0falseEsce dal ciclo

Do…while: almeno una esecuzione

Con do…while la condizione si controlla dopo il corpo. Il blocco viene quindi eseguito almeno una volta. Qui il punto e virgola dopo la condizione è necessario.

C++
int numero = 0;
do {
    cout << numero << endl;
    numero = numero + 1;
} while (numero < 0);
Risultato dell’esempio
0

Un dato numerico da richiedere di nuovo

Una richiesta di input è un caso utile per do…while: prima leggi, poi valuti se ripetere. La condizione descrive quando il dato non va accettato.

C++
int voto = 0;
do {
    cout << "Voto da 1 a 10: ";
    cin >> voto;
} while (voto < 1 || voto > 10);
cout << "Voto accettato: " << voto << endl;
Risultato dell’esempio
Voto da 1 a 10: 0
Voto da 1 a 10: 11
Voto da 1 a 10: 7
Voto accettato: 7
Da ricordare. Questo esempio controlla l’intervallo dei numeri. Presume input numerico e non gestisce parole inserite al posto del voto.

Ripetere fino a un valore di fine

Un valore particolare può indicare che l’utente vuole terminare. Nell’esempio, 0 è il valore di fine e non cambia la somma. Se è il primo input, il ciclo non viene eseguito.

C++
int numero = 0;
int somma = 0;
cin >> numero;
while (numero != 0) {
    somma = somma + numero;
    cin >> numero;
}
cout << "Somma: " << somma << endl;
Risultato dell’esempio
Con input 4, 6, 0:
Somma: 10

For

Il ciclo for riunisce inizializzazione, condizione e aggiornamento. È comodo quando le ripetizioni seguono un contatore.

Le tre parti del for

La prima parte si esegue una volta. La seconda si controlla prima di ogni ripetizione. La terza aggiorna il contatore dopo il corpo. Le tre parti sono separate da punti e virgola.

C++
for (int i = 1; i <= 4; i = i + 1) {
    cout << i << " ";
}
cout << endl;
Risultato dell’esempio
1 2 3 4

Contare, saltare valori e scendere

Cambiando inizio, limite e aggiornamento puoi stampare i numeri pari o eseguire un conto alla rovescia. Verifica sempre se il valore finale deve essere incluso.

C++
for (int i = 2; i <= 8; i = i + 2) {
    cout << i << " ";
}
cout << endl;
for (int i = 3; i >= 1; i = i - 1) {
    cout << i << " ";
}
Risultato dell’esempio
2 4 6 8
3 2 1

Accumulare una somma

Un accumulatore conserva il risultato dei giri precedenti. Dichiaralo e inizializzalo prima del ciclo, se deve restare disponibile anche dopo. Azzerarlo a ogni giro farebbe perdere il totale.

C++
int somma = 0;
for (int i = 1; i <= 4; i = i + 1) {
    somma = somma + i;
}
cout << "Totale: " << somma << endl;
Risultato dell’esempio
Totale: 10

Cicli annidati

Un ciclo interno completa le proprie ripetizioni per ogni giro di quello esterno. Nell’esempio ci sono due righe e tre stampe per riga: sei asterischi in totale.

C++
for (int riga = 1; riga <= 2; riga = riga + 1) {
    for (int colonna = 1; colonna <= 3; colonna = colonna + 1) {
        cout << "*";
    }
    cout << endl;
}
Risultato dell’esempio
***
***

Una tabella di prodotti

Due contatori possono rappresentare riga e colonna. Ogni cella contiene il prodotto dei loro valori.

C++
for (int riga = 1; riga <= 3; riga = riga + 1) {
    for (int colonna = 1; colonna <= 3; colonna = colonna + 1) {
        cout << riga * colonna << " ";
    }
    cout << endl;
}
Risultato dell’esempio
1 2 3
2 4 6
3 6 9

For-each: visitare i valori

Il for basato su intervallo, spesso chiamato for-each, visita gli elementi di una sequenza. Puoi iniziare con una stringa: a ogni giro la variabile lettera contiene un suo carattere. Questa forma esiste da C++11.

C++
string parola = "mare";
for (char lettera : parola) {
    cout << lettera << endl;
}
Risultato dell’esempio
m
a
r
e

For-each e array

La stessa forma visita i valori di un array, che studieremo nel capitolo dedicato. Qui basta osservare che numeri conserva tre interi. La variabile numero riceve una copia del valore a ogni giro.

C++
int numeri[3] = {4, 7, 9};
for (int numero : numeri) {
    cout << numero << " ";
}
Risultato dell’esempio
4 7 9

Un esempio: la tabellina

Quando il numero di ripetizioni è noto, il contatore rende esplicito il percorso. Da 1 a 10 inclusi ci sono dieci giri.

C++
int numero = 3;
for (int i = 1; i <= 10; i = i + 1) {
    cout << numero << " x " << i << " = "
         << numero * i << endl;
}
Risultato dell’esempio
3 x 1 = 3
3 x 2 = 6
…
3 x 10 = 30
Da ricordare. Qui i puntini abbreviano le righe centrali: il programma stampa tutte e dieci le righe.

Break e continue

Puoi terminare una ripetizione prima del limite previsto oppure saltare soltanto la parte restante di un giro.

Break termina il ciclo

break esce dal ciclo più interno che lo contiene. Il programma continua con le istruzioni dopo il ciclo.

C++
for (int numero = 1; numero <= 8; numero = numero + 1) {
    if (numero == 6) {
        break;
    }
    cout << numero << " ";
}
cout << endl << "Fine" << endl;
Risultato dell’esempio
1 2 3 4 5
Fine

Continue salta un giro

continue salta le istruzioni rimaste nell’iterazione corrente. Nel for viene poi eseguito l’aggiornamento del contatore, prima del controllo successivo.

C++
for (int numero = 1; numero <= 5; numero = numero + 1) {
    if (numero == 3) {
        continue;
    }
    cout << numero << " ";
}
Risultato dell’esempio
1 2 4 5

Break e continue con while

Anche while supporta queste istruzioni. Con continue si torna direttamente al controllo: un aggiornamento scritto più avanti nel corpo non sarebbe eseguito. Nell’esempio incrementiamo prima del possibile salto.

C++
int numero = 0;
while (numero < 5) {
    numero = numero + 1;
    if (numero == 3) {
        continue;
    }
    cout << numero << " ";
}
Risultato dell’esempio
1 2 4 5
Da ricordare. Dentro uno switch, break esce dallo switch. Dentro il ciclo interno di due cicli annidati, break non termina anche il ciclo esterno.

Array

Un array conserva una sequenza di elementi dello stesso tipo. L’indice ti permette di scegliere un elemento senza dare a ogni valore un nome diverso.

Dichiarare un array

Scrivi il tipo, il nome e il numero di elementi tra parentesi quadre. I valori iniziali sono racchiusi tra graffe. Gli array tradizionali usati qui hanno dimensione fissa.

C++
int voti[5] = {6, 8, 5, 7, 9};
cout << voti[0] << endl;
cout << voti[2] << endl;
Risultato dell’esempio
6
5

Indici e modifica degli elementi

Il primo elemento ha indice 0; l’ultimo di un array di cinque elementi ha indice 4. L’indice indica una posizione, mentre il valore è ciò che quella posizione contiene.

IndicePosizioneValore iniziale
0Prima6
1Seconda8
2Terza5
3Quarta7
4Quinta9
C++
int voti[5] = {6, 8, 5, 7, 9};
voti[2] = 6;
cout << voti[2] << endl;
Risultato dell’esempio
6
Da ricordare. voti[5] è fuori limite. Un array tradizionale non controlla automaticamente gli indici: leggere o scrivere oltre i limiti provoca comportamento non definito, non necessariamente un messaggio di errore.

Array e cicli

Un ciclo può visitare ogni elemento. Con un array di N valori, usa gli indici da 0 a N - 1, quindi la condizione i < N. Puoi mostrare anche la posizione.

C++
const int N = 3;
int punteggi[N] = {12, 18, 15};
for (int i = 0; i < N; i = i + 1) {
    cout << "Posizione " << i << ": " << punteggi[i] << endl;
}
Risultato dell’esempio
Posizione 0: 12
Posizione 1: 18
Posizione 2: 15

For-each su un array

Se vuoi soltanto i valori, un for-each evita di scrivere gli indici. La variabile del ciclo conserva una copia: modificarla in questa forma non modifica l’array.

C++
int punteggi[] = {12, 18, 15};
for (int punteggio : punteggi) {
    cout << punteggio << " ";
}
Risultato dell’esempio
12 18 15

Omettere la dimensione

Se inserisci i valori iniziali, il compilatore può dedurre la dimensione. int dati[] = {2, 4, 6}; crea tre elementi. Senza dimensione e senza valori, invece, non può sapere quanto spazio serve.

Omettere la dimensione nella dichiarazione non rende l’array modificabile nella lunghezza. Gli elementi possono cambiare valore, ma l’array resta della dimensione con cui è stato creato.

Omettere i valori iniziali

Puoi dichiarare l’array indicando soltanto la dimensione e assegnare i valori in seguito. Per evitare valori numerici non inizializzati, la forma = {} inizializza tutti gli elementi a zero.

C++
int dati[3] = {};
dati[0] = 12;
dati[1] = 8;
cout << dati[0] << " " << dati[1] << " " << dati[2] << endl;
Risultato dell’esempio
12 8 0

Dimensione in byte e numero di elementi

sizeof(array) indica lo spazio totale in byte. Non è direttamente il numero di elementi. Dividendo per sizeof(array[0]) ottieni il numero di elementi negli array dichiarati come in questi esempi.

C++
int dati[] = {2, 4, 6};
auto elementi = sizeof(dati) / sizeof(dati[0]);
cout << "Elementi: " << elementi << endl;
Risultato dell’esempio
Elementi: 3
Da ricordare. Se un int occupa 4 byte, questo array occupa 12 byte. La formula non dipende dall’ipotesi dei 4 byte: usa il rapporto fra dimensioni effettive.

Usare la dimensione in un ciclo

Conservando il numero di elementi, il limite del ciclo si adatta ai valori della dichiarazione. Il for-each resta una forma semplice quando l’indice non ti serve.

C++
int dati[] = {2, 4, 6};
int elementi = sizeof(dati) / sizeof(dati[0]);
for (int i = 0; i < elementi; i = i + 1) {
    cout << dati[i] << " ";
}
Risultato dell’esempio
2 4 6

Media e massimo di una sequenza

La somma parte da zero; il massimo parte da un valore realmente presente, qui il primo. Il tipo decimale della divisione permette di conservare la parte frazionaria della media.

C++
int voti[5] = {6, 8, 5, 7, 9};
int somma = 0;
int massimo = voti[0];
for (int i = 0; i < 5; i = i + 1) {
    somma = somma + voti[i];
    if (voti[i] > massimo) {
        massimo = voti[i];
    }
}
cout << "Media: " << somma / 5.0 << endl;
cout << "Massimo: " << massimo << endl;
Risultato dell’esempio
Media: 7
Massimo: 9

Array multidimensionali

Un array a due dimensioni organizza i valori come una tabella. Il primo indice sceglie la riga, il secondo la colonna. Anche qui gli indici partono da 0.

C++
int tabella[2][3] = {{1, 2, 3}, {4, 5, 6}};
cout << tabella[1][2] << endl;
tabella[0][1] = 9;
cout << tabella[0][1] << endl;
Risultato dell’esempio
6
9

Scorrere righe e colonne

Due cicli annidati visitano ogni cella: quello esterno sceglie la riga; quello interno visita tutte le colonne di quella riga. È utile per tabelle di punteggi o dati organizzati per righe.

C++
int tabella[2][3] = {{1, 2, 3}, {4, 5, 6}};
for (int riga = 0; riga < 2; riga = riga + 1) {
    for (int colonna = 0; colonna < 3; colonna = colonna + 1) {
        cout << tabella[riga][colonna] << " ";
    }
    cout << endl;
}
Risultato dell’esempio
1 2 3
4 5 6

Strutture

Una struttura raggruppa campi anche di tipi diversi che descrivono la stessa entità. È come una scheda con più informazioni.

Creare una struttura

La parola chiave struct apre la definizione dei campi. A differenza di un array, i campi possono avere tipi diversi. Questa prima forma crea direttamente una variabile chiamata scheda.

C++
struct {
    string nome;
    int eta;
    double media;
} scheda;

scheda.nome = "Alex";
scheda.eta = 16;
scheda.media = 7.5;
Da ricordare. Includi <string> per i campi di testo. La definizione della struttura termina con un punto e virgola dopo la graffa e gli eventuali nomi delle variabili.

Accedere ai campi

Il punto seleziona un campo di una specifica variabile. Puoi leggerlo, mostrarlo o assegnargli un nuovo valore. Tutti gli altri campi rimangono indipendenti.

C++
cout << scheda.nome << endl;
cout << scheda.eta << endl;
scheda.media = 8.0;
cout << scheda.media << endl;
Risultato dell’esempio
Alex
16
8
Da ricordare. Questo frammento continua l’esempio precedente: usa la stessa variabile scheda dopo aver assegnato i suoi campi.

Più variabili della stessa struttura

Alla fine di una definizione puoi dichiarare più variabili separate da virgole. Ogni variabile possiede i propri campi: assegnare il nome di una non cambia quello dell’altra.

C++
struct {
    string titolo;
    int pagine;
} primo, secondo;

primo.titolo = "Il viaggio";
primo.pagine = 180;
secondo.titolo = "Oltre la collina";
secondo.pagine = 240;
cout << primo.titolo << endl;
cout << secondo.titolo << endl;
Risultato dell’esempio
Il viaggio
Oltre la collina

Dare un nome al tipo

Una struttura con un nome introduce un tipo riutilizzabile. Studente è il tipo, alunno è una variabile di quel tipo. I valori tra graffe inizializzano i campi nell’ordine della definizione.

C++
#include <iostream>
#include <string>
using namespace std;

struct Studente {
    string nome;
    int eta;
    double media;
};

int main() {
    Studente alunno = {"Alex Rossi", 16, 7.5};
    cout << alunno.nome << ": " << alunno.media << endl;
    return 0;
}
Risultato dell’esempio
Alex Rossi: 7.5

Un array di strutture

Puoi creare un array in cui ogni elemento è una scheda. L’indice sceglie la scheda e il punto seleziona il campo. Il codice seguente usa il tipo Studente appena definito.

C++
Studente classe[2] = {
    {"Alex", 16, 7.5},
    {"Samira", 17, 8.0}
};
for (int i = 0; i < 2; i = i + 1) {
    cout << classe[i].nome << ": " << classe[i].media << endl;
}
Risultato dell’esempio
Alex: 7.5
Samira: 8
